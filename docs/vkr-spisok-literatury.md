## Примечания для вставки в Word / LaTeX

- Внутритекстовые ссылки: **[номер]** без пробела перед скобкой, точка после ссылки — **после** скобки: `…в формате JSONB [5].`
- Несколько источников подряд: **[5], [6]**, а не [5-6] (по рекомендациям ННГУ).
- Документацию SurveyJS, FastAPI, Docker, React допускается цитировать в разделе «Материалы и методы»; в общий список они включены как электронные ресурсы с URL и датой обращения.
- Для бакалавриата объём **22** источника достаточен; при требовании кафедры увеличить список до 25+ добавьте 2–3 статьи из RSCI по темам «информационные системы в социологии» или «веб-опросы» (eLIBRARY.RU).
- Перед сдачей сверьте выходные данные печатных изданий (год, страницы, издательство) с экземпляром в библиотеке ННГУ или каталогом eLIBRARY.
