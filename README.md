## Для исследователя

### Регистрация и вход

Откройте `http://localhost:5173` и зарегистрируйтесь через форму. После успешной регистрации система перенаправит в административный кабинет на `/admin/surveys`. При следующих визитах достаточно войти под своим логином и паролем.

Токен авторизации сохраняется в браузере автоматически. Если сессия истечёт, система вернёт вас на страницу входа.

### Создание анкеты

В разделе `/admin/surveys` нажмите «Создать анкету». Откроется редактор на базе SurveyJS Creator с панелью Designer.

Заполните название и описание анкеты, затем добавляйте вопросы из палитры компонентов слева: одиночный выбор, множественный выбор, шкала, текстовый ввод, рейтинг, матрица и другие типы. Каждый вопрос можно настроить через панель свойств справа: текст вопроса, варианты ответов, обязательность заполнения.

Вкладка Preview позволяет посмотреть, как анкета будет выглядеть для респондента, не покидая редактор.

### Условная логика вопросов

Чтобы вопрос показывался только при определённых условиях, откройте его свойства и найдите поле **Visible If**. Туда вписывается логическое выражение вида:

```
{question1} = 'Да'
```

Это означает: вопрос появится только если на вопрос с именем `question1` дан ответ «Да». Доступны также **Required If** (вопрос обязателен при условии) и **Enable If** (вопрос доступен для редактирования при условии).

Имя вопроса (`question1` в примере) видно в панели свойств в поле Name. Если своё условие проверить сложно, в редакторе есть значок-вопрос со справкой по синтаксису.

### Настройка сроков и лимитов

Нажмите на значок шестерёнки в редакторе, чтобы открыть диалог настроек. Доступны параметры:

- дата и время начала приёма ответов;
- дата и время окончания;
- максимальное число ответов;
- разрешён ли анонимный режим.

После окончания срока или достижения лимита анкета автоматически закрывается для новых ответов.

### Публикация анкеты

Когда анкета готова, нажмите «Сохранить», затем «Опубликовать». После публикации анкета становится доступна по публичной ссылке вида:

```
http://localhost:5173/s/<id_анкеты>
```

Скопировать ссылку можно прямо из списка анкет, кнопкой рядом с названием.

Внесённые после публикации правки не ломают уже собранные ответы: при каждом сохранении создаётся новая версия анкеты, а старые ответы остаются привязаны к версии, по которой они были даны.

### История версий

Панель истории версий находится справа в редакторе. В ней видны все сохранённые версии анкеты с указанием, кто и когда внёс изменения, и краткое описание того, что изменилось.

Чтобы вернуться к одной из прежних версий, нажмите «Восстановить» у нужной версии и подтвердите действие. Восстановление создаёт новую версию на основе выбранной, текущие данные не теряются.

### Просмотр статистики

На странице `/admin/surveys/<id>/stats` доступны:

- общее число сессий, завершённых и незавершённых;
- процент завершения (completion rate);
- средний процент прохождения;
- распределение ответов по каждому вопросу в виде диаграмм;
- таблица всех сессий с указанием статуса, прогресса и времени.

### Экспорт результатов

На странице статистики доступны ссылки на экспорт в формате CSV и JSON. Можно выбрать, включать ли незавершённые ответы. При необходимости анонимизации идентификаторы респондентов в выгрузке можно скрыть, указав соответствующий параметр запроса.

## Для респондента

### Прохождение анкеты

Откройте ссылку на анкету, полученную от исследователя. Авторизация не требуется.

Если анкета поддерживает только персонифицированный режим, на первом экране нужно будет ввести свой идентификатор (например, номер студенческого билета или ФИО). Если режим анонимный, это поле можно пропустить.

После начала отвечайте на вопросы по порядку. В верхней части экрана отображается полоса прогресса. Некоторые вопросы могут появляться или скрываться в зависимости от предыдущих ответов: это нормальное поведение анкеты, настроенное исследователем.

По завершении нажмите кнопку отправки. Появится экран с подтверждением, что ответы сохранены.

### Прерывание и продолжение

Если вы закрыли вкладку браузера или потеряли соединение, не волнуйтесь: все ответы сохраняются автоматически в процессе заполнения. При повторном открытии той же ссылки на этом же устройстве и в этом же браузере анкета восстановится с того места, где вы остановились.

Если соединение временно пропало, вы увидите предупреждение о проблеме с сетью, но уже введённые ответы не потеряются: следующая успешная отправка подхватит все изменения.

Обратите внимание: восстановление прогресса работает в пределах одного браузера на одном устройстве. Если вы откроете ссылку с другого устройства, анкета начнётся заново (если только это не персонифицированный режим, привязанный к вашему идентификатору).

## Установка для разработчика

### Требования

- Docker и Docker Compose
- Node.js (для локальной разработки фронтенда без контейнера)
- Python 3.11 (для локальной разработки бэкенда без контейнера)

### Быстрый запуск через Docker

```bash
docker compose up --build
```

Это поднимет три контейнера: PostgreSQL на порту 5433, FastAPI-бэкенд на порту 8001, фронтенд на порту 80 (production-сборка через nginx).

Проверка, что бэкенд работает:

```bash
curl http://localhost:8001/healthz
# {"status": "ok", "db": "connected"}
```

### Запуск в режиме разработки

Нужны два процесса: API и Vite dev-сервер.

**Шаг 1.** Поднимите базу данных и API:

```bash
cp backend/.env.example backend/.env   # при первом запуске
docker compose up -d --build survey-db survey-api
curl http://127.0.0.1:8001/healthz
```

**Шаг 2.** В отдельном терминале запустите фронтенд:

```bash
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`. Vite автоматически проксирует запросы `/api` на `http://127.0.0.1:8001`.

### Миграции базы данных

Если нужно применить миграции вручную:

```bash
docker compose up -d survey-db
cd backend
cp .env.example .env
./migrate.sh
```

Подробное описание возможных проблем с Alembic и их решений приведено в основном README репозитория.

### E2E-тесты

Чтобы проверить, что все основные сценарии работают (регистрация, вход, создание анкеты, публикация, автосохранение, прохождение):

```bash
docker compose up --build -d
python3 scripts/e2e_smoke.py
```

Для более полной проверки доступны также `e2e_survey_lifecycle.py`, `e2e_public_flow.py` и `e2e_stats_and_export.py` в каталоге `scripts/`.

### Структура проекта

```
backend/    — FastAPI-приложение, миграции Alembic, бизнес-логика
frontend/   — React-приложение на Vite, SurveyJS Creator и Runner
docs/       — дополнительная документация
scripts/    — вспомогательные и e2e-скрипты
```

### Интеграция с АСНИ

Подсистема может работать как самостоятельное приложение или как удалённый модуль (remote) в общей оболочке АСНИ через Vite Module Federation. Имя модуля — `surveyConstructor`, экспортируются компонент `App` и API-клиент. Подробности конфигурации — в `frontend/vite.config.ts`.
